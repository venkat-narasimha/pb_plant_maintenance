🔧 Plant Maintenance — Technician Quick Reference

Your one-page guide to the daily maintenance workflow
Role: Technician
App: pb_plant_maintenance v1.0
Site: dev-erp.duckdns.org

1 My Daily Flow

  1. Log in at /app/plant-maintenance
  2. Click the Maintenance Orders shortcut
  3. Filter: Status = Planned or In Progress
  4. You only see orders assigned to your team or to you
  5. Open the order → read Operations table → click Start Work

👉 Can't see any orders? Ask your PM Manager to add you to an Asset Maintenance Team.

2 Start & Run Work

  1. Open order → top-right menu ⋮ Actions
  2. Start Work → status flips to In Progress, actual start stamped
  3. Carry out each Operation row on the order
  4. Use spare parts from the Required Parts list (already reserved for you)
  5. When finished: ⋮ Actions → Record Confirmation

3 Record Confirmation

  1. Confirmation Type: Partial = more work left Final = job done
  2. Operation #: match the Op # from the order (e.g. 10)
  3. Labor Hours: actual time spent (e.g. 2.5)
  4. Materials Used: add rows for every part consumed (item + qty + warehouse)
  5. Equipment Status After: Running / Idle / Down
  6. Save → Submit. Final confirmation auto-completes the order & posts costs.

! Report a Breakdown (Notification)

  1. Workspace → Maintenance Notifications → Add
  2. Type: Malfunction · Priority: High or Critical
  3. Select Equipment + fill Short Description
  4. Tick Breakdown if the machine is down now
  5. Save + Submit → PM Manager is auto-emailed on Critical
  6. Planner will convert it into a Maintenance Order for you

M Log a Measurement

  1. Workspace → Measurement Documents → Add
  2. Select the Measuring Point (e.g. bearing temp, vibration)
  3. Enter Reading Value + date
  4. Submit — counter updates automatically
  5. If the reading is outside limits, the system auto-creates a High-priority Notification

💡 Check your ToDo list daily for due measurement tasks.

Call PM Manager directly — system email may delay.

✅ End-of-Shift Checklist

  • All open orders I worked on have a Confirmation submitted
  • Any breakdowns reported as Notifications
  • Due measurements logged (check ToDo)
  • Spare parts used are entered on Confirmations
  • Notes added for the next shift on Work Performed
